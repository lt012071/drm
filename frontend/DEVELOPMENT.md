# 開発環境とテスト環境の設定

このプロジェクトでは、開発環境とテスト環境を柔軟に切り替えることができます。

## 🚀 開発モード

### 通常のローカル開発 (バックエンドサーバー使用)

```bash
npm run dev
```

- バックエンドサーバー (http://localhost:3001) に接続
- データベースとの通信を含む完全なシステムテスト
- 認証機能も有効

### フロントエンド単体開発 (モック使用)

```bash
npm run dev:mock
```

- モックサービスを使用してフロントエンド機能をテスト
- バックエンドサーバーやデータベースが不要
- 認証もスキップ

## 🧪 テスト環境

### ユニットテスト (モック使用)

```bash
npm run test
```

- 自動的にモックサービスと認証スキップが有効
- `.env.test` の設定を使用

### モック環境でのテスト

```bash
npm run test:mock
```

- 明示的にモック環境でテスト実行

## ⚙️ 環境設定

### .env (通常のローカル開発用)

```env
VITE_API_URL=http://localhost:3001
VITE_USE_MOCK_SERVICE=false  # 実際のバックエンドを使用
VITE_SKIP_AUTH=false         # 認証を有効
```

### .env.test (テスト用)

```env
VITE_API_URL=http://localhost:3001
VITE_USE_MOCK_SERVICE=true   # モックサービスを使用
VITE_SKIP_AUTH=true          # 認証をスキップ
```

## 🔧 環境変数の説明

| 変数 | 説明 | 値 |
|------|------|-----|
| `VITE_API_URL` | バックエンドAPIのURL | `http://localhost:3001` |
| `VITE_USE_MOCK_SERVICE` | モックサービス使用フラグ | `true` / `false` |
| `VITE_SKIP_AUTH` | 認証スキップフラグ | `true` / `false` |

## 📝 使い分けガイド

### 🎯 通常のローカル開発: `npm run dev`
- システム全体の動作確認
- バックエンドとの連携テスト
- データベース操作の確認
- 認証フローの確認

### 🧪 フロントエンド開発: `npm run dev:mock`
- UIコンポーネントの開発
- フロントエンドロジックのデバッグ
- バックエンドが起動していない時の開発
- 素早いプロトタイピング

### ✅ ユニットテスト: `npm run test`
- 自動テスト実行
- CI/CDパイプライン
- 機能の単体テスト

## 🚦 トラブルシューティング

### バックエンド接続エラー
通常の開発で接続エラーが発生する場合:
1. バックエンドサーバーが起動しているか確認
2. 一時的にモック環境で開発: `npm run dev:mock`

### 認証エラー
認証でエラーが発生する場合:
1. 環境変数 `VITE_SKIP_AUTH=true` を設定
2. または `npm run dev:mock` を使用
